# Slei shadcn/ui Rebuild Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Slei Desktop's visible UI layer with shadcn/ui and the provided tweakcn theme while preserving existing product behavior.

**Architecture:** The desktop app owns the new shadcn primitives directly under `apps/desktop/src/components/ui`, with Slei-specific business composition in `apps/desktop/src/components` and `apps/desktop/src/features`. The old `animal-island-ui` dependency and `packages/ui` workspace package are removed only after all desktop imports and tests are migrated. Core state, daemon bridge calls, routes, i18n keys, and workflow callbacks remain intact.

**Tech Stack:** pnpm workspace, React 19, Vite 7, Tauri 2, TypeScript, Vitest, Tailwind CSS v4, shadcn CLI, shadcn/ui, tweakcn registry theme, lucide-react.

- Create `apps/desktop/components.json`: shadcn CLI config scoped to the desktop app.
